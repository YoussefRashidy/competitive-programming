# Competitive Programming

C++ solutions to competitive programming problems across Codeforces, CSES, AtCoder, USACO, and other judges.

## Structure

Solutions are organized by judge, then by problem ID or name:

```
CP/
├── AtCoder/
├── CodeForces/
├── CSES/
├── DMOJ/
├── EOlymp/
├── Gym/
├── HackerRank/
├── Kattis/
├── POJ/
├── SPOJ/
├── USACO/
└── UVA/
```
